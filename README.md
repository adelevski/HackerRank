## Using the exercises

Read a file before running it with Python 3. Most contain hardcoded examples and
print results; some read HackerRank-style input from standard input. There is no
shared runner or automated correctness suite. Judge scaffolding and input
assumptions may need adapting for local use.

When revisiting an exercise, add the problem link, the reasoning behind the
approach, its time/space complexity and a few edge cases. Preserve useful earlier
approaches when they explain what changed.

Problem names and platform scaffolding come from [HackerRank](https://www.hackerrank.com/).
Record any editorial or community source used when revisiting a solution.
